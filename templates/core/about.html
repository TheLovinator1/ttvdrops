About TTVDrops

TTVDrops archives limited-time drops, rewards and campaigns from Twitch, Kick and Chzzk. It keeps past campaigns searchable and provides RSS feeds and a JSON API for updates.

Features

  • Twitch, Kick and Chzzk campaign archives
  • RSS and Atom feeds
  • Search and historical data
  • Open data under CC0

Data and API

Data is collected from public sources and may contain errors. Use at most one API request per second, and prefer dataset downloads for bulk analysis. The service may limit or block abusive usage.
