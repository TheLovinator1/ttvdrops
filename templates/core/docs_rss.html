RSS & Atom Feeds

Follow new Twitch, Kick, and Chzzk drops in a feed reader, Discord server, or bot. Every feed is also available as Atom and a Discord-formatted variant.

There is no rate limit, but please don't be stupid.

Feed formats

RSS

Standard RSS 2.0 feeds supported by almost every feed reader.

Atom

Atom 1.0 feeds with ISO-8601 timestamps for modern readers.

Discord

Atom feed with Discord Markdown and relative timestamps.
