RSS Feeds Documentation

Subscribe to Twitch and Kick Drops updates using standard RSS, Atom, or Discord-flavored feeds. Looking for programmatic access? Read the JSON API documentation (/api/v1/docs/).

RSS

.rss

Standard RSS 2.0 feeds with full campaign details. Widely supported across classic, minimalist, and self-hosted feed readers.

Atom

.atom

Standard Atom 1.0 feeds with the same campaign data as RSS, using ISO-8601 published and updated timestamps preferred by modern readers.

Discord-flavored

/discord/

Atom feeds with the same data formatted for Discord Markdown and relative timestamps (e.g. <t:1773450272:R>).

Query parameters: Twitch campaign feeds accept ?limit=<int> to adjust item count and ?hide_paid=1 to hide drops that need subscriptions.
