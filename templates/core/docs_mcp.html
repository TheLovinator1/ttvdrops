MCP Server Documentation

The TTVDrops MCP server lets AI clients search the archive of Twitch, Kick and Chzzk drop campaigns. It is read-only and unauthenticated, matching the public website and JSON API. The endpoint is {{ mcp_url }}.

Connect a client

Add the server to an MCP client as a Streamable HTTP server. It uses the MCP protocol directly, so there is no separate API key or token. 

{
  "mcpServers": {
    "ttvdrops": {
      "type": "http",
      "url": "{{ mcp_url }}"
    }
  }
}

Looking for REST instead? The JSON API documentation is available at /api/v1/docs/, and bulk data can be downloaded from datasets.

Available tools

Every tool is read-only and returns structured data. Dates are ISO 8601, and timestamps are UTC unless an offset is given. Searches return at most 100 campaigns per call; use the limit parameter to narrow large result sets.

Discovery

AI clients and registries can read the machine-readable server card at {{ mcp_server_card_url }}. It describes the endpoint, transport and capabilities without opening an MCP session. The same information is also available to MCP clients through the protocol's tools/list method.
